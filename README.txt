➥ Template Installation
  How to install the template ?
When you buy the template you have to unzip it using winrar or 7zip then you change the existing files of the Tebex default theme
 with those of the zip template of the same name ( missing zip files should not be edited )
Webstore > Design > Appearance > Template
(You have to use the Flat theme)

Attention! style.css file paste in "Theme" ( way: Webstore > Design > Appearance > Theme ) and activate it!

All change options are in layout.html and style.css (Theme)
Where is layout.html?
  Webstore > Design > Appearance > Template > Edit > layout.html
Where is style.css?
  Webstore > Design > Appearance > Theme > Edit > style.css

You can change Template style to RUST in layout.html, set tebex_store to 'rust'
